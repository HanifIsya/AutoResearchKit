# Portable Academic Writing Skill v3.0 — Research → Evidence → Manuscript → Audit → Handoff

**Mulai dari:** `00_START/START_HERE.md`. Untuk chat AI baru, unggah ZIP ini, lalu kirim prompt di `00_START/MASTER_PROMPT_SHORT.md` atau `00_START/MASTER_PROMPT_FULL.md`. Skill ini **bukan otomatis terinstal**. AI baru harus membaca `SKILL.md` lalu file cabang yang sesuai.

**Yang disediakan**: SOP akademik lintas genre; tutorial pencarian sumber dan pembentukan `.url` shortcut; katalog sumber otoritatif yang dicek pada 2 Nov 2026; contoh best-practice yang dibuat sendiri; template 9 ledger/plan; contoh grafik dan kode; script untuk membangun folder shortcuts; Word manual; template pergantian chat; register audit.

**Yang tidak disediakan**: klaim naskah siap terbit, izin untuk mengunggah seluruh PDF berhak cipta, data penelitian asli, lisensi reproduksi gambar pihak ketiga, koneksi permanen ke mesin pencari atau tool AI. ZIP referensi adalah koleksi **tautan + metadata + status verifikasi**, bukan perpustakaan full-text. Untuk tugas baru, katalog harus **ditambah sumber domain-spesifik**; jangan mengutip pedoman umum seolah-olah hasil empiris topik baru.

## Cara pakai cepat

- **Sesi 1, riset:** unggah ZIP + brief/topik. Perintah `Jalankan mode RESEARCH_ZIP, cari sumber empiris dan penulisan yang relevan, buat katalog dan folder Windows .url, lalu evidence map dengan status pencarian`. 
- **Sesi 2, manuskrip:** unggah brief + evidence/source ZIP + data. Perintah `Jalankan mode FULL_MANUSCRIPT sesuai genre. Jangan membuat data, pakai figure register dan nomor sitasi final; kirim .docx/.md serta audit terpisah`.
- **Sesi 3, handoff:** gunakan `templates/new_chat_handoff.md`; unggah paket evidence dan prompt singkat.

Gunakan format sumber yang **sesuai venue**, bukan karena contoh di sini menggunakan IEEE. Contoh grafik dan naskah mini **simulasi**, bukan temuan empiris.

**Prompt per mode:** `00_START/RESEARCH_ZIP_PROMPT.md`, `00_START/FULL_MANUSCRIPT_PROMPT.md`, `00_START/REVISE_AND_AUDIT_PROMPT.md`, `00_START/NEXT_CHAT_PROMPT.md`. Use one per stage; the short master prompt is useful when only one message can be copied.
