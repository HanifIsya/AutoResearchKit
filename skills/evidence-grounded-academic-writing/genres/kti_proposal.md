# Genre: KTI, scientific proposal, student innovation paper

Read official format first: some KTI use Bab I–V, some use IMRaD or `Pendahuluan–Pembahasan–Penutup`. Don't falsely put outcomes of unperformed prototypes in “Hasil”. For proposals, write `rencana metode` and target evaluation, not completed experiment.

Build traceability: problem and target beneficiary; primary statistics and local context; nearest literature; gap; specific novelty (conceptual/method/implementation/context); proposed intervention/system; operational flow; methods, dataset and evaluation plan; feasibility (costs/technical/organizational/legal); measured or simulated outputs with explicit tags; limitation and responsible use; funding/timeline if relevant; references.

Tables/visuals likely useful: literature comparative matrix, stakeholder pain-point tree, architecture/data flow, study design, baseline–target metrics (**target not result**), feasibility/risk matrix and 12/24-month timeline when necessary. For market/finance tables, label assumption, year, currency, source and sensitivity. Do not add every framework simply to look comprehensive.
