# Why the reusable workflow is structured this way

The user's prior technical-report workflow emphasized (a) initial literature/source search and organised ZIP; (b) real data/OOF/code provenance; (c) strict distinction between trained procedures, cached outputs, planned operations and unverified scores; (d) academic prose with IEEE in-text citation tied to an exact claim; (e) nondecorative tables, charts, numbered equations, source notes and detailed appendices; (f) multirole audit and full Word layout checking; (g) an MD handoff that allows a new conversation to continue without reconstructing all earlier messages.

These traits have been generalized into cross-domain authoring rules. The current skill intentionally does not bundle original competition datasets, raw manuscripts, confidential materials, model checkpoints or a promise that an older study can be reproduced outside its original environment. Domain-specific figures/results and publisher constraints must be derived afresh for each research project.

The user-provided `Panduan_Penulisan_Akademik_v2.0_Advanced.md` is included unchanged as a reference to preserve detail. The canonical routing instructions for this portable package are in `SKILL.md` and the current playbooks; consult the source guide where it gives a more detailed epistemic or review method.
