# Playbook 05 — Academic writing and exact genre fit

## Draft order

1. Fix title/RQ and the **maximum legitimate contribution**.
2. Write Methods/approach with evidence inventory (or design in proposals).
3. Write Results only from actual measured outputs.
4. Write Discussion with comparisons, alternative explanations, limitations, implications.
5. Write introduction as the reason this study had to be done, using real source evidence.
6. Compose abstract and conclusion **last** to prevent claiming unsupported results.
7. Finalize references, figure cross-references and metadata.

For essays, outline argument/counterargument from verified sources first; for literature reviews, synthesize themes before writing introduction. These are heuristics, not inviolable genre rules.

## Difference between title, claim and finding

Title names question/problem and method scope, not a sales slogan. Introduction establishes urgency proportional to actual data and shows gap via closest studies. Methods specify what was executed vs proposed. Results report outcomes, not mechanisms conjectured after seeing them. Discussion explains meaning and alternatives, not repeating entire metrics table. Conclusion answers the question under studied conditions, with no new numbers introduced.

## Paragraph architecture

The topic sentence must assert something checkable rather than “is important”. Choose evidence that directly supports it. Explain the inferential bridge where evidence is indirect. Add limiting conditions whenever omission changes interpretation. Avoid over-hedging direct observations, but never erase meaningful uncertainty. Natural paragraphs have **variable** lengths; neither 3 sentences nor 4 bullet points is a universal ideal. Keep one consistent technical term for one construct.

## Phrase-level red team

| Unhelpful | Professional correction principle |
|---|---|
| `Di era digital yang terus berkembang...` | start with a concrete, evidenced failure mode or population |
| `AI merevolusi proses secara signifikan` | specify function/outcome; if unmeasured, say designed to test |
| `Berdasarkan berbagai penelitian...` | identify papers and concrete contrast; attach citations near claims |
| `Pertama, kedua, ketiga` repeated | organize by causal or methodological transition, not enumeration ritual |
| `Sistem terbukti efektif` after interface mockup | `prototipe dirancang ...; efektivitas belum diuji` |
| `Hasil menunjukkan peningkatan drastis` | report baseline, endline, absolute and relative difference, uncertainty |

Do not replace all passive voice. Scientific procedures often properly use passive. Do not convert an exact borrowed quotation into a false paraphrase or keep an uncited borrowed string. Use target venue's instructions for italicization, acronyms, Indonesian terms, captions and section levels.

## Citation placement example

Bad: `Internet semakin meluas. Sentimen berubah. Sistem harus otomatis. [1] [2] [3]` — three different propositions with unclear support.

Better **pattern** (replace with real verified facts before use): `Laporan [lembaga] mencatat [nilai indikator] dari [populasi] pada [tahun] [1]. Namun, indikator tersebut mengukur [apa yang diukur], bukan [klaim yang tidak diukur]. Penelitian ini mengevaluasi [fungsi terukur] pada [sampel], sehingga implikasi operasional memerlukan evaluasi tambahan.`

## What never belongs in a final reader manuscript

Prompts, instruction hierarchy, user-confirmation transcript, raw AI critique, TODO without clear labeling, invented reviewer quotes, bibliography of sources not actually cited, JSON debugging data, empty figure slots without purpose, and inaccurate statements about tests performed. Separate these in internal audit and handoff folders.
