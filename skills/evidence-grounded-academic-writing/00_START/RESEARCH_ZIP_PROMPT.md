# Prompt mode: RESEARCH_ZIP — copy-paste and fill fields

Bertindaklah sebagai research librarian, domain researcher, citation auditor, methodologist dan academic-writing editor. Pelajari skill ZIP yang saya upload terlebih dahulu, khususnya `SKILL.md` dan `playbooks/02_source_hunt_and_reference_zip.md`. Topik saya `[ISI]`, genre `[ISI]`, target venue/rubrik `[ISI/UNKNOWN]`, periode referensi `[ISI/REASONED]`, bahasa `[ISI]`.

**Tahap awal wajib: riset web sungguhan**, bukan menyusun daftar paper dari ingatan. Cari 5 jalur: aturan penulisan venue, sumber primer untuk masalah/urgensi, 3–10 atau lebih studi terdekat berdasarkan task/context/metrik, literatur teori/metode/validasi, serta best-practice jurnal dan contoh tabel/figure yang benar-benar cocok. Verifikasi metadata tiap sumber dari DOI/penerbit/Crossref, periksa isi minimal bagian relevan, beri status akses (full text/abstract/metadata), directness, data, keterbatasan, dan klaim yang boleh didukung. Jika menyebut jurnal Scopus Q1/Q2 atau SINTA 1–3, cek status per jurnal, tahun dan kategori/masa berlaku pada portal yang tepat. Jangan mengasumsikan semua sumber relevan adalah jurnal.

Buat `RESEARCH_SOURCES_<topic>.zip` dengan katalog CSV, search log, evidence cards, top reading list, literature matrix, citation-entailment ledger, status indexing dan lisensi, daftar pustaka BibTeX/RIS bila metadata ada, serta file Windows `.url` untuk tiap link sumber. Kelompokkan shortcut dalam folder `venue_rules`, `domain`, `nearest_neighbors`, `method`, `visual_examples`. Jika PDF full-text berlisensi terbuka dan akses pengunduhan benar-benar tersedia, simpan hanya jika sah; selebihnya shortcut saja, jangan mengklaim ZIP berisi PDF. Jelaskan mana contoh tampilan figure paper yang dapat dipelajari dan mana yang belum boleh direproduksi. Jangan mulai menulis naskah panjang sebelum peta sumber dan gap yang terbukti tersedia. Berikan ZIP, index Markdown dan ringkasan penilaian relevansi yang bisa dipakai langsung untuk tahap penulisan.
