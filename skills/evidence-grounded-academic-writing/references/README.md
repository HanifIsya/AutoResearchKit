# Reference starter kit

This starter contains 21 general academic writing/methodology links checked against live official or publisher pages on 2026-11-02, organized as Windows `.url` shortcuts. It is intentionally **not** a set of 21 topic-specific journal studies or a claim that all are Q1/Q2/SINTA journals. Most are standards, publisher guides, official portals or exemplar papers.

- `source_catalog.csv`: source metadata, license/access/check status, purpose.
- `reading_index.md`: choose which guides best match your new document.
- `verified_examples.bib`: limited DOI-backed bibliography examples.
- `shortcuts/`: one `.url` per source, organized by functional category.
- `shortcuts/INDEX.md`: clickable inventory.

For a real project, use `playbooks/02_source_hunt_and_reference_zip.md` to create a new topical ZIP after real web searching. A source shortcut **does not** imply article full text was downloaded, read in its entirety, or legally redistributable. Status flags note which sources were inspected beyond metadata.
